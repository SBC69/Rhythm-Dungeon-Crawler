# Dungeon theme artwork

Mode: built-in imagegen. The existing corridor.png and door.png remain the crypts set and provide the perspective and coarse pixel style reference. Each additional theme has one opaque corridor and one transparent door sprite.

## ash_forges/corridor.png

Use case: stylized-concept. Asset type: game dungeon corridor background. Image 1 is perspective and PIXEL STYLE REFERENCE. Create a distinct new environment in exactly the same coarse pixel-art visual family. Wide landscape 16:9 image filling canvas, first-person eye-level central vanishing point, symmetrical receding corridor, side walls and vaulted ceiling, large tiled floor in foreground. Soot-black basalt masonry and heavy iron ribs, old chains on side walls, forge grates and narrow lava channels along wall bases, restrained ember orange and dark rust red illumination. Strong square pixel clusters, like a 320x180 game background enlarged with nearest neighbor. Dark fantasy limited palette, flat stepped shading with sharp pixel outlines. Foreground center remains plain and uncluttered so three interactive door sprites can be overlaid. Only a small dark arch far in the distance. No large foreground doors, hero hands, enemies, text, interface, photorealistic textures, gradients, blur or smooth lighting.
