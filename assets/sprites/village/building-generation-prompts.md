## Stage 0–2 edit prompt construction

Use case: precise-object-edit. Asset type: transparent isometric village building game sprite, restoration progression variant. Image 1 is the edit target, the fully restored STAGE 3 building. Preserve the EXACT camera, isometric angle, diamond ground footprint, framing, canvas dimensions, building location and coarse square pixel size of image 1. Draw the SAME building at an earlier repair stage. Do not add objects outside its base. Transparent background, complete silhouette and empty margins. Bold stepped low-resolution pixel art, hard pixel shading, same dark fantasy palette and materials. No text, UI, people, backdrop, cutoffs, gradients, blur or pasted floating symbols. 

stage_0.png: STAGE 0: abandoned ruin of this same structure, roof largely collapsed, broken upper walls and beams, rubble contained on base, cold unlit windows, no smoke or functioning fire, torn ruined cloth. Retain enough shape to recognize this building. Fountain dry if present, toppled statue top if present.

stage_1.png: STAGE 1: first repairs of this same ruined building, lower walls stabilized, rough timber scaffolding and a few new roof beams, still substantial holes in roof and upper walls, some neatly stacked rebuilding supplies on base. Just one dim warm light. Fountain still dry if present, monument partly rebuilt if present. Clearly halfway between ruin and usable building.

stage_2.png: STAGE 2: this same building is functional and mostly repaired, intact lower walls, roof about 85 percent repaired with one rough patch, only a small amount of scaffolding, fewer finishing ornaments and lamps than stage 3. Moderate light, simple work equipment. Fountain working with modest water if present. Clearly more restored than stage1 but less finished than image1.

For every building, concatenate the shared edit prompt above with the matching stage instruction. Input: that building's new stage_3.png. The same prompts are used for forge, houses, square, chronicler, marketplace and alchemist.

Mode: built-in imagegen. Each stage is generated separately on a transparent canvas. Stage 3 uses the previous building for identity and the pixel knight for coarse pixel style. Stages 0–2 use the new restored building as their geometry reference.
