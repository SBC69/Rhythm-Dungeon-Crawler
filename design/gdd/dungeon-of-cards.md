## Detailed Design

### 1. Начало похода

Новый поход начинается автоматически. Значения сбрасываются:

| Показатель | Стартовое значение |
|---|---:|
| Этаж / комната | 1 / 1 |
| Здоровье / максимум | 50 / 50 |
| Золото | 40 |
| Базовая мощь | 2 |
| Временное усиление / заточка | 0 / 0 |
| Пройденные комнаты / убитые монстры | 0 / 0 |

В руке две стопки по две карты. Начальная общая мощь — **6**, бонус к кубикам — **+2**, снижение входящего урона — **1**.

### 2. Комнаты, двери и этажи

На обычной комнате видны три двери. Выбор любой запускает анимацию и генерацию встречи: **75% монстр, 25% ловушка/проклятие**. Содержимое не закрепляется за дверью заранее, индекс выбранной двери не влияет на генерацию. После побега можно снова выбрать дверь и получить другую встречу в той же комнате.

Комнаты 1–9 обычные. Комната 10 всегда содержит босса; видна одна центральная дверь. Победа над боссом и выбор награды открывают лагерь. Номер комнаты остаётся 10 до спуска на следующий этаж. Ограничения максимального этажа нет.

Комната засчитывается после выбора награды за монстра или продолжения после ловушки. Побег комнату не засчитывает. На следующем этаже номер комнаты возвращается к 1.

### 3. Мощь, здоровье и бой

Мощь героя складывается из базы, экипировки и временного усиления. Если она **не меньше** мощи монстра, доступна кнопка победы без урона. Победа требует подтверждения игроком; автоматического завершения по одному сравнению нет.

Если монстр сильнее, игрок может применить доступные карты, принять штрафной бой или попытаться сбежать. Штрафной бой наносит сырой урон `10 × разница мощи`, затем применяется снижение брони. Если герой выжил, монстр считается побеждённым и появляется выбор награды. Если HP достигло нуля, поход завершён поражением.

У монстра нет отдельной шкалы HP или последовательности ходов: встреча разрешается сравнением мощи и выбранным действием. В бою при изменении характеристик пересчитываются доступные кнопки.

### 4. Побег

Побег доступен при превосходстве монстра. Бросаются две кости d6. К сумме добавляется текущий бонус амулета. Успех — сумма не ниже порога **или любой дубль**. Проверка суммы 12 отдельно присутствует в коде, но 6+6 уже является дублем.

Есть один бесплатный переброс; кольцо фортуны добавляет ещё один. Переброс предлагается после неудачи, уменьшает остаток на 1 и заменяет обе кости. Урон за неудачный бросок не списывается немедленно: игрок выбирает переброс либо подтверждает принятие штрафа.

При успехе герой возвращается в коридор без урона. При принятом провале получает штраф, и, если выжил, также возвращается в коридор **той же комнаты**. Побег не выдаёт награды, не увеличивает счётчик убийств/комнат и не сбрасывает временное усиление — сброс происходит при продвижении.

Порог и разница мощи фиксируются при открытии экрана; бонус кубиков читается при оценке и подтверждении. Остаток перебросов инициализируется при открытии, а не пересчитывается после каждой смены амулета.

### 5. Ловушки и проклятия

Случайно выбирается один из трёх шаблонов. Итоговый бросок — **2d6 + бонус амулета**, хотя анимация и часть текста говорят об одном кубике.

- Результат ≥ DC: урона нет.
- DC−2 ≤ результат < DC: половина сырого урона, округлённая вниз, минимум 1; затем действует броня.
- Результат < DC−2: полный сырой урон с бронёй. Для алтаря дополнительно уменьшается базовая мощь на 1, минимум до 1.

Ослабление базы сохраняется на следующих этажах до нового похода. Дубль сам по себе не спасает от ловушки. Дополнительные перебросы амулета здесь не используются. После разрешения и подтверждения продолжения живой герой переходит к следующей комнате; карт за ловушку нет.

### 6. Карты, рука и экипировка

Пять типов: WEAPON, ARMOR, POTION, BUFF, AMULET. Три слота: оружие, броня, амулет; по одному предмету каждого типа. Замена возвращает прежний предмет в руку. Есть программная операция снятия, но отдельное действие снятия в UI не обнаружено.

Клик по предмету экипирует его, по зелью — лечит, по свитку — увеличивает временную мощь. Экипировку можно перетаскивать в совместимый слот; оружие также принимается зоной кузницы. Во время магазина клик по основной руке блокируется, а мини-карты магазина продаются.

Текущая стопка определяется **только ID карты**. Использование или продажа уменьшает count на 1; при последней единице запись удаляется. Ограничение размера руки/стопки не задано; рука прокручивается горизонтально.

Зелье тратится и при полном HP. Свиток разрешено использовать вне боя, если рука доступна; временный бонус сбрасывается при продвижении комнаты или этажа. Ограничения только фазой боя в модели нет.

## Formulas

Обозначения: F — этаж от 1; R — комната 1–10; B — базовая мощь шаблона; P — мощь героя; M — мощь монстра; A — снижение урона бронёй; U — уровень заточки до покупки; X — случайное целое от −1 до +1.

| Расчёт | Формула текущего кода |
|---|---|
| Мощь героя | база + power оружия + power брони + power амулета + временный buff; отсутствующий power=0 |
| Обычный монстр | max(2, B + 2×(F−1) + floor((R−1)/3) + X) |
| Индекс босса | (F−1) mod 2 |
| Мощь босса | B + 4×(F−1) |
| Победа без урона | P ≥ M |
| Сырой штраф боя | 10×(M−P), применяется в ветке P<M |
| Входящий урон | max(1, сырой урон − A); HP после = max(0, HP до − урон) |
| Лечение | HP после = min(max_HP, HP до + лечение) |
| Разница для побега | D = max(1, M−P) на момент открытия |
| Порог побега | clamp(6+D, 7, 11) |
| Бросок побега | d6 + d6 + текущий dice_bonus; успех при достижении порога или дубле |
| Число перебросов | 1 + extra_rerolls на момент открытия |
| Сырой штраф провала побега | 10×D |
| Порог ловушки | min(10, DC шаблона + floor((F−1)/2)) |
| Сырой урон ловушки | урон шаблона + 3×(F−1) |
| Частичный сырой урон | max(1, floor(сырой урон ловушки / 2)) |
| Power награды | power шаблона + (F−1) |
| Heal награды | heal шаблона + 5×(F−1) |
| Power_buff награды | power_buff шаблона + (F−1) |
| Цена заточки | 40 + 30×U |
| Эффект заточки | power += 2; U += 1 |

Формулы выписаны из реализации; баланс не валидирован плейтестом. Например, босс этажа 2 имеет мощь 16: 12+4; на этаже 3 лич имеет мощь 17: 9+8. Не следует принимать из одного линейного выражения вывод о сбалансированности всей прогрессии.
